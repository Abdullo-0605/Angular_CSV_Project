3 — Main Logic: File → Parse → Chart
User clicks file input & selects a .csv file
onFileSelected(event) fires
Template: (change)="onFileSelected($event)"
Is file present?
Checks input.files?.[0]
NO → set status "No file selected", set fileLoaded = false, RETURN
YES ↓
Set fileName signal = file.name
Set status signal = "Reading file..."
Set fileLoaded signal = false
Read file content
const text = await file.text()
Async: reads entire CSV as a string
Store raw text → fileContent signal
parseCsv(text)
1. Split text by newlines (\r?\n)
2. Trim each line, remove empty lines
3. First line → headers[] (split by comma)
4. Remaining lines → rows[][] (each value → Number())
Example: headers = ["Time", "C1_Voltage", "L1_Current", "VDC1_Voltage Difference"] — rows = [[0, 2.12e-8, 0.021, 1], [0.1, 0.0008, 0.048, 1], ...]
transformToChartData(parsed)
1. labels = first column of every row (Time values)
2. For each remaining header, create a dataset object:
  • label = header name
  • data = that column's values from all rows
3. Return { labels, datasets }
Store chart JSON → parsedDataText signal
Set status = "File loaded successfully"
Set fileLoaded = true
Reset file input: input.value = ''
Allows re-selecting the same file later
setTimeout → renderChart(chartData)
Delayed by 0ms so Angular can render the canvas element first
(because @if (fileLoaded()) conditionally shows the canvas)
Does chartCanvas ViewChild exist?
NO → RETURN (nothing to render on)
YES ↓
Does a previous chart instance exist?
YES → call chart.destroy() to clean up old chart
Get 2D context from <canvas> element
new Chart(ctx, config)
• Type: line
• Datasets mapped with: borderWidth=2, pointRadius=0, tension=0.2
• X axis: linear, min=0, max=60 (hardcoded)
• Y axis: min=0, max=2.0 (hardcoded)
• responsive=true, maintainAspectRatio=false
Chart rendered on screen
